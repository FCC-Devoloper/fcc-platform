# Глубокий ремонт (v2)

## Редакторы в админке (главная причина ошибок)
- **Новости и проекты**: теперь есть «Редактировать», «Скрыть/Опубликовать», «Закрепить» (новости), «Выбор студии» (проекты), рубрики, дата публикации, подробное описание, результат, заказчик, год, загрузка картинок. Правка меняет только присланные поля (раньше пустые поля затирали данные).
- **Планы и команда**: добавлена правка (раньше только создать/удалить), фото команды можно загрузить, участника можно скрыть.
- **Тексты сайта**: форма строится из `lib/content-defaults.js` (около 80 полей: О нас, цифры, услуги, шаги работы, заголовки, подвал, контакты, SEO). Пустое поле = текст по умолчанию. Сохранение одной кнопкой.
- **Visual Editor**: переписан. Раньше искал элементы до построения страницы и не сохранял стили/действия, а на сайте они не применялись. Теперь: выбор клика, цвет/размер/выравнивание/действие кнопки, сохранение, сброс к исходному, режимы Компьютер/Планшет/Телефон. Предпросмотр больше не создаёт «гостей» в чате.
- Исправлены кнопки в списках: `onclick="editPromo("id")"` ломался из-за кавычек (в т.ч. «Редакт.» у акций).
- При просроченной сессии админка сама выходит на страницу входа.

## Дизайн и логика сайта
- Новости: закреплённые сверху, рубрики-фильтры, дата, окно «Читать далее», кнопка действия. Будущая дата = отложенная публикация.
- Проекты: карточка с картинкой/заглушкой, рубрика, «Выбор студии», окно «Подробнее» (заказчик, год, результат, фишки, технологии), демо.
- Новые разделы главной: «О нас» + цифры, «Как мы работаем», расширенный подвал. Все тексты правятся в админке.
- Скрытые проекты/новости не видны на сайте; список проектов не отдаёт исходный код демо.

## Ошибки и безопасность
- Сломанная `esc()` в `site-render.js` (XSS) исправлена; ссылки `javascript:` отбрасываются на сервере и в браузере.
- `fcc_data.json`: запись по очереди через временный файл (параллельные сохранения портили файл), автокопия `.bak` раз в сутки, при повреждении сервер восстанавливается из `.bak`, а не затирает данные.
- Удалён старый `app.js` (содержал вход админа на публичных страницах). Внутренние страницы используют общие модули.
- Убран вход по паролю в открытом виде из `auth.js`; удалены скрипты grok из HTML; CORS закрыт (свои адреса: `CORS_ORIGINS` в `.env`); лимит на реакции.
- Контакты: пустые поля скрываются, заглушки `hello@fcc.replace` убраны.
